# Portfolio de Iván Ramos

Portfolio personal en HTML, CSS y JavaScript sin librerías. Diseño «Embers Foundry»: una pantalla fija con dos estados (portada y proyectos) y un panel con sobre mí, experiencia, formación, proyectos y contacto.

Ver en local: `python3 -m http.server 8765` y abrir http://localhost:8765/

Archivos: `index.html`, `style.css`, `app.js`, `assets/` (fotos y capturas). `_antiguo/` guarda el diseño anterior (no se sube a git).
Más detalles y decisiones en `CLAUDE.md`.
